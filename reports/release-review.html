What changed

Verification limits

All internal links and object IDs are checked. Figure, example, and equation labels remain derived from source order, with selected historical fixtures and rendered-page inspection; the July PDF encodes many labels graphically, so complete label-by-label equality is not certified. Accessibility checks cover language, headings, image alternatives, table headers, link names, equation copying, and desktop/mobile layout; they are not a formal PDF/UA or screen-reader certification.

Release handling

The version is cp2e-ver1.0, independent of numbering profile. The PDF filename is cp2e-ver1.0.pdf and the website archive is cp2e-ver1.0-static-html.zip. Runtime and font hashes are checked before release rendering. The artifacts are local; nothing has been published or uploaded.
